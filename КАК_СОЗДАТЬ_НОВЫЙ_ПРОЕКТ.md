# Как создать новый проект в портфолио

## Шаг 1: Создать HTML файл проекта

1. Скопируйте файл `new-project-template.html` и переименуйте его (например, `my-new-project.html`)
2. Замените все упоминания `project-*` в атрибутах `data-i18n` на уникальные ключи для вашего проекта
3. Заполните контент:
   - Измените `<title>` в `<head>`
   - Обновите переводы в объекте `translations` (секции `ru` и `en`)
   - Добавьте изображения/видео в папку `images/` или `video/`
   - Обновите пути к изображениям/видео в HTML

## Шаг 2: Добавить карточку проекта на главную страницу

Откройте `index.html` и найдите секцию `<section class="projects">`. 

Добавьте новую карточку проекта перед закрывающим тегом `</div>` секции `projects-container`:

```html
<a href="my-new-project.html" class="project-card-link">
    <div class="project-card">
        <img src="images/your-project-image.png" alt="Описание проекта" class="project-image">
        <div class="overlay-rectangle">
            <h3 class="overlay-title" data-i18n="project-N-title">Название проекта</h3>
            <p class="overlay-description" data-i18n="project-N-description">Краткое описание проекта</p>
        </div>
    </div>
</a>
```

**Важно:** Замените `N` на номер вашего проекта (например, `project-5-title`, `project-5-description`)

## Шаг 3: Добавить переводы в index.html

В файле `index.html` найдите объект `translations` в секции `<script>`. 

Добавьте переводы для карточки проекта в оба языка:

```javascript
const translations = {
    ru: {
        // ... существующие переводы ...
        'project-N-title': 'Название проекта',
        'project-N-description': 'Краткое описание проекта'
    },
    en: {
        // ... существующие переводы ...
        'project-N-title': 'Project Title',
        'project-N-description': 'Brief project description'
    }
};
```

## Пример структуры:

```
Портфолио/
├── index.html                    (главная страница - добавить карточку)
├── my-new-project.html           (новая страница проекта)
├── styles.css                    (общие стили)
├── images/
│   └── my-project-image.png      (изображение для карточки)
└── video/                        (опционально, для видео)
    └── my-project-video.mov
```

## Советы:

1. **Изображения:** 
   - Для карточки на главной странице рекомендуется размер примерно 420x250px
   - Для детальных изображений в проекте используйте качественные изображения

2. **Видео:**
   - Формат: .mov или .mp4
   - Для автовоспроизведения добавьте атрибуты: `autoplay loop muted playsinline`

3. **Переводы:**
   - Всегда добавляйте переводы для обоих языков (RU и EN)
   - Используйте одинаковые ключи `data-i18n` в HTML и в объекте `translations`

4. **Секции проекта:**
   - Вы можете убрать секцию "Ключевые решения", если она не нужна
   - Можно использовать либо обычный текст (`<p>`), либо список (`<ol>`)
