# Папка для изображений

Поместите сюда ваши изображения:

## Необходимые файлы:

1. **avatar.jpg** - ваше фото для аватара (рекомендуемый размер: 400x400px или больше, квадратное)
2. **project-nda.jpg** - скриншот проекта NDA (рекомендуемый размер: 1200x800px или больше)
3. **project-portal.jpg** - скриншот проекта Портал (рекомендуемый размер: 1200x800px или больше)

## Форматы файлов:

Поддерживаются форматы: `.jpg`, `.jpeg`, `.png`, `.webp`

## Как добавить изображения:

1. Скопируйте ваши изображения в эту папку (`images/`)
2. Убедитесь, что имена файлов точно совпадают:
   - `avatar.jpg` (или `.png`, `.webp`)
   - `project-nda.jpg` (или `.png`, `.webp`)
   - `project-portal.jpg` (или `.png`, `.webp`)

3. Если вы используете другие имена файлов, обновите пути в `index.html`:
   ```html
   <img src="images/ваше-имя-файла.jpg" alt="..." class="avatar-image">
   ```

## Оптимизация:

Для лучшей производительности рекомендуется:
- Оптимизировать изображения перед загрузкой (используйте инструменты типа TinyPNG, ImageOptim)
- Использовать формат WebP для лучшего сжатия
- Размер файлов должен быть разумным (не более 1-2 МБ каждое)
